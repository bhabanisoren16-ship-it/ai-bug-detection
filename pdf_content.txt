2. Phase 1: Code Debugging — Five-Stage Detection & Highlighting Workflow
Phase 1 operates continuously from keystroke-level IDE editing through CI/CD compilation and fuzz
testing. Each stage refines the candidate bug set and attaches precise character and byte coordinates so
the highlighting engine can render unambiguous visual overlays.
Stage 1.1: Incremental Lexical, Syntactic & Lossless AST Indexing
The source file is parsed using an error-recovering incremental parser (such as Tree-sitter or Clang
LibTooling). Every token and AST node n is annotated with a 5-tuple source coordinate Span(n) =
(file_id, start_line, start_col, end_line, end_col) alongside raw UTF-8 byte offsets [byte_start,
byte_end). Syntax errors (missing semicolons, unmatched braces, illegal type tokens) insert explicit ERROR
nodes into the tree and immediately trigger primary red squiggly highlights without aborting downstream
analysis of valid functions.
Stage 1.2: Static Control-Flow (CFG), Data-Flow (DFG) & Taint Propagation
The engine lowers the AST into Static Single Assignment (SSA) form, constructing basic blocks linked by
conditional and unconditional control edges. Over this graph, two primary analyses execute:
Ownership & Memory State Machine: Tracks every pointer and resource handle across states
{Uninitialized → Allocated → Active → Freed / Closed}. Any transition from Freed → Dereferenced
flags a Use-After-Free (CODE-MEM-001); exiting scope in state Allocated without reaching Freed
flags a Memory/Resource Leak (CODE-MEM-002).
Source-to-Sink Taint Analysis: Marks external inputs (network sockets, CLI arguments, HTTP
payloads, hardware MMIO reads) as Tainted Sources. Taint propagates through assignments and
arithmetic operations unless cleared by a registered Sanitizer (bounds check, parameterized query,
cryptographic hash). Reaching a sensitive Sink (strcpy, SQL execution, shell invocation, array index)
while tainted triggers a critical vulnerability alert.

Stage 1.3: Dynamic Instrumentation, Symbolic Execution & Spectrum Localization
Static analysis alone can suffer from path explosion or false positives on complex pointer aliasing. Stage
1.3 compiles the target with compiler sanitizers (AddressSanitizer, UndefinedBehaviorSanitizer,
ThreadSanitizer) and pairs coverage-guided fuzzing with an SMT solver (Z3). When a branch condition C
guards a potential crash site, the symbolic engine negates prefix path constraints Φ ∧ ¬C to solve for
concrete input bytes that force execution into the buggy state. Across the test suite, execution bitmaps
record which statements run in passing versus failing tests, feeding the Ochiai Spectrum-Based Fault
Localization (SBFL) formula.
Stage 1.4: AI / GNN Semantic Bug Detection & Root-Cause Ranking
Logical bugs—such as off-by-one loop bounds, swapped function arguments, incorrect comparison
operators (< instead of <=), or missing lock acquisitions—often obey language syntax and memory safety
rules. To catch these, the engine constructs a heterogeneous code property graph combining AST parent-
child links, CFG execution edges, and DFG def-use edges. A pre-trained Graph Neural Network + Code
Transformer evaluates each statement's contextual embedding, outputting a probability distribution over
bug categories and generating a candidate AST repair patch.
Stage 1.5: Phase 1 Multi-Layer Visual Highlighting Mechanics
Once defects are detected and ranked, the highlighting subsystem converts internal graph nodes back
into visual editor decorations via the Language Server Protocol (LSP) and SARIF v2.1.0:
Layer 1 — Exact Token Span Highlight: Renders a high-contrast background tint and wavy underline
across [start_col, end_col) on the offending line (Crimson #D92D20 for Critical/Error; Amber #F79009
for Warning; Cobalt #0066CC for Info/Trace).
Layer 2 — Causal Data-Flow Trail (Backward Slice Badges): Rather than highlighting only the crash
line, the engine highlights the entire causal chain with numbered inline step pills—e.g., [1. Allocated
L15] → [2. Freed on Error Branch L17] → [3. Crash: Dereferenced L19].
Layer 3 — Ghost-Text Inline Diff Preview: Displays the AI-synthesized fix directly beneath the
highlighted bug using red strikethrough for the defective statement and green insertion styling for the
verified patch.
3. Phase 2: Circuit Debugging — Five-Stage Hardware & Netlist Workflow
Phase 2 extends automated debugging into digital RTL (Verilog, SystemVerilog, VHDL), synthesized gate-
level netlists, analog/mixed-signal SPICE subcircuits, and physical silicon/PCB layouts. Because hardware
executes massively in parallel and is governed by continuous physical laws (timing propagation, clock
skew, voltage drop, capacitance), Phase 2 combines graph-theoretic topological checks with physical
timing and waveform tracing.
Stage 2.1: HDL Elaboration, Netlist Synthesis & Hypergraph Extraction
Hardware description files and SPICE decks are elaborated into a canonical directed hypergraph G = (V, E).
Vertices V represent circuit primitives (combinational LUTs, AND/OR/XOR gates, sequential D-flip-flops,
latches, SRAM macros, or MOSFET/CMOS transistors), while hyperedges E represent nets connecting a
driver pin to one or more sink pins. Every vertex and net retains bidirectional cross-reference pointers to
the originating RTL file/line, schematic symbol coordinates (x, y), and physical layout polygon bounding
boxes.

Stage 2.2: Structural ERC, Clock Domain Crossing (CDC) & Static Timing Analysis (STA)
Before running expensive simulations, the engine performs exhaustive structural and timing verification
across the hypergraph:
Electrical & Structural Rule Checking (ERC): Traverses strongly connected components (Tarjan's SCC
algorithm) over combinational gates to flag Combinational Feedback Loops (CIRC-ERC-003) that
cause oscillation. Scans net degree distributions to identify Undriven/Floating Input Nets (CIRC-ERC-
004), Multi-Driver Bus Contention, and excessive capacitive fan-out.
Static Timing Analysis (STA): Propagates signal arrival times forward and required times backward
across all timing arcs using Liberty (.lib) cell delay tables and parasitic RC interconnect delays. Flags
any register-to-register path where Setup Slack or Hold Slack falls below zero.
Clock Domain Crossing (CDC) Verification: Traces clock trees from root PLL/pad sources to every
sequential element. Whenever a data path launches from flip-flop FFA (clocked by CLK_A) and is
captured by FFB (clocked by asynchronous CLK_B) without traversing a valid multi-flop synchronizer,
async FIFO, or handshake cell, the engine flags a Metastability CDC Violation (CIRC-CDC-002).
Stage 2.3: Formal SAT/SMT Model Checking & Waveform X-Propagation Tracing
To uncover deep functional bugs in state machines, arbiters, and pipelined datapaths, Stage 2.3 compiles
SystemVerilog Assertions (SVA) and unrolls the circuit transition relation T(st, st+1) across k clock cycles
into a SAT/SMT formula. If a safety property fails, the solver emits a minimal counterexample waveform
trace. Concurrently, the waveform analyzer ingests simulation dumps (.vcd / .fsdb) and traces unknown
logic states (1'bX or high-impedance 1'bZ) backward through time and logic cones to pinpoint the exact
cycle and uninitialized register or contention net where the X originated.
Stage 2.4: AI / GNN Hardware Fault Localization & Analog IR-Drop Analysis
When a functional simulation fails an end-to-end testbench check (e.g., a processor core computes a
wrong ALU result 40 cycles later), hundreds of gates lie within the structural Cone of Influence (COI). A
Gate-Level Graph Convolutional Network (GCN) processes node features (gate type, toggle rate, fan-
in/fan-out, observability/controllability metrics SCOAP) and failing vs. passing waveform toggle signatures
to assign an exact fault probability P(fault | vi) to every gate. For analog/SPICE and power delivery
networks, the engine solves nodal conductance matrices G · V = I to isolate thermal and IR-drop voltage
droop hotspots.
Stage 2.5: Phase 2 Synchronized 4-View Cross-Probe Highlighting Engine
Hardware engineers debug across four coupled representations simultaneously. When the AI/software
engine isolates a circuit bug, it broadcasts a linked highlight event across all four views:
1. View 1 — RTL Source Editor: Highlights the exact Verilog/VHDL signal declaration and behavioral
assignment statement (e.g., assign alu_carry_n7 = ...).
2. View 2 — Gate-Level Schematic Canvas: Colors the failing logic cone and net wires by defect class—
Crimson (#D92D20) for negative setup/hold slack paths, Amber (#F79009) for unsynchronized CDC
crossings, and Violet (#7A5AF8) for floating nets or X-propagation paths—while dimming non-
participating background gates to 25% opacity.
3. View 3 — Digital/Analog Waveform Viewer: Drops synchronized vertical time markers at tlaunch, tglitch,
and tcapture, shading the exact setup/hold violation window or metastable X region in translucent
crimson.

    # ---------- PHASE 1: SOFTWARE CODE DEBUGGING & HIGHLIGHTING ----------
    def analyze_phase1_code(self, filename: str, source_code: str) -> list:
        diags, lines = [], source_code.splitlines()
        tree = ast.parse(source_code, filename=filename)
        freed_vars, taint_vars, zero_vars = {}, {}, set()
        for node in ast.walk(tree):
            if isinstance(node, ast.Assign):
                for tgt in node.targets:
                    if isinstance(tgt, ast.Name):
                        fn = getattr( getattr(node.value, "func", None), "id", "")
                        if isinstance(node.value, ast.Call) and fn in ("input", "recv"):
                            taint_vars[tgt.id] = (node.lineno, node.col_offset)
                        if isinstance(node.value, ast.Constant) and node.value.value == 0:
                            zero_vars.add(tgt.id)
            if isinstance(node, ast.Call):
                fn = getattr(node.func, "id", "")
                if fn in ("free_buf", "close_fd") and node.args:
                    arg0 = node.args[0]
                    if isinstance(arg0, ast.Name):
                        freed_vars[arg0.id] = (node.lineno, node.col_offset)
                else:
                    for arg in node.args:
                        if isinstance(arg, ast.Name) and arg.id in freed_vars:
                            f_ln, f_col = freed_vars[arg.id]
                            if node.lineno > f_ln:
                                diags.append(self._code_diag(
                                    "CODE-MEM-001", "CRITICAL", 0.96, filename,
                                    node.lineno, arg.col_offset,
                                    arg.col_offset + len(arg.id),
                                    lines[node.lineno - 1],
                                    f"Use-After-Free of {arg.id} (freed L{f_ln})",
                                    [{"step": 1, "ev": "Freed", "ln": f_ln},
                                     {"step": 2, "ev": "Deref", "ln": node.lineno}],
                                    f"- {lines[node.lineno-1].strip()}\n+ return -EINVAL"
                                ))
            if isinstance(node, ast.BinOp) and isinstance(node.op, (ast.Div, ast.Mod)):
                rhs = node.right
                is_zero = (isinstance(rhs, ast.Constant) and rhs.value == 0) or (
                           isinstance(rhs, ast.Name) and rhs.id in zero_vars)
                if is_zero:
                    diags.append(self._code_diag(
                        "CODE-NUM-003", "CRITICAL", 0.93, filename,
                        node.lineno, node.col_offset, node.col_offset + 12,
                        lines[node.lineno - 1], "Unchecked division by zero",
                        [{"step": 1, "ev": "Zero divisor reaches /", "ln": node.lineno}],
                        "+ ratio = (num / denom) if denom != 0 else 0.0"
                    ))
        return diags
    def _code_diag(self, rule, sev, score, fn, ln, c0, c1, src, msg, tr, diff):
        st = self.PALETTE[sev]
        caret = (" " * c0) + ("~" * max(1, c1 - c0))
        return {
            "phase": "PHASE_1_CODE", "rule_id": rule, "severity": sev,
            "scores": {"r_total": score},
            "code_span": {"file": fn, "line": ln, "start_col": c0, "end_col": c1},
            "highlight_style": {"color_hex": st["hex"], "underline": st["style"]},
            "visual_overlay": f"L{ln}: {src}\n     {caret} [{rule}: {msg}]",
            "causal_trace": tr, "auto_remediation": {"unified_diff": diff}

    # ---------- PHASE 2: CIRCUIT NETLIST, CDC & STA DEBUGGING ----------
    def analyze_phase2_circuit(self, netlist: dict) -> list:
        diags = []
        gates = {g["id"]: g for g in netlist["gates"]}
        for net in netlist["nets"]:
            if len(net["drivers"]) == 0:
                diags.append({
                    "phase": "PHASE_2_CIRCUIT", "rule_id": "CIRC-ERC-004",
                    "severity": "VIOLET_NET", "scores": {"r_total": 0.89},
                    "highlight_style": {"color_hex": "#7A5AF8", "layer": "NET_TRACE"},
                    "circuit_probe": {"net": net["name"], "sinks": net["sinks"],
                                      "gdsii_bbox": net["bbox"]},
                    "message": f"Floating undriven net {net['name']} -> X-prop."
                })
        for p in netlist["timing_paths"]:
            src, dst = gates[p["launch_ff"]], gates[p["capture_ff"]]
            t_comb = sum(gates[g]["delay_ns"] for g in p["comb_cone"])
            slack = (p["clk_period_ns"] + p["cap_clk_delay_ns"]) - (
                p["lnch_clk_delay_ns"] + src["clk_to_q_ns"] +
                t_comb + dst["setup_ns"] + p["uncertainty_ns"]
            )
            if slack < 0.0:
                diags.append({
                    "phase": "PHASE_2_CIRCUIT", "rule_id": "CIRC-STA-001",
                    "severity": "CRITICAL", "scores": {"r_total": 0.97},
                    "slack_ns": round(slack, 3),
                    "highlight_style": {"color_hex": "#D92D20", "cone": p["comb_cone"]},
                    "circuit_probe": {"launch": src["id"], "capture": dst["id"],
                                      "vcd_ps": p["vcd_window_ps"], "bbox": p["bbox"]},
                    "auto_remediation": {"action": "Insert pipeline reg or upsize MUX."}
                })
            if src["clock_domain"] != dst["clock_domain"] and not p.get("synced"):
                diags.append({
                    "phase": "PHASE_2_CIRCUIT", "rule_id": "CIRC-CDC-002",
                    "severity": "WARNING", "scores": {"r_total": 0.94},
                    "highlight_style": {"color_hex": "#F79009", "marker": "CDC_ASYNC"},
                    "circuit_probe": {"src_clk": src["clock_domain"],
                                      "dst_clk": dst["clock_domain"],
                                      "net": p["crossing_net"], "bbox": p["bbox"]},
                    "auto_remediation": {"action": "Insert 2-FF synchronizer cell."}
                })
        return diags
